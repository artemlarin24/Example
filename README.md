#Example
Основные команды Git

git init — создать Git-репозиторий в текущей папке.

git clone <ссылка> — скачать репозиторий с GitHub на компьютер.

git status — посмотреть, какие файлы были изменены.

git add <файл> — подготовить один файл к сохранению.

git add . — подготовить все изменённые файлы к сохранению.

git commit -m "текст" — сохранить изменения в истории Git.

git push — отправить свои изменения на GitHub.

git pull — скачать последние изменения с GitHub.

git log — посмотреть историю коммитов.

git log --oneline — посмотреть историю коммитов в коротком виде.

git diff — посмотреть, что именно изменилось в файлах.

Ветки

git branch — посмотреть список веток.

git branch <имя> — создать новую ветку.

git switch <имя> — перейти на другую ветку.

git switch -c <имя> — создать новую ветку и сразу перейти в неё.

git merge <имя> — добавить изменения из другой ветки в текущую.

git branch -d <имя> — удалить ветку.

Работа с GitHub

git remote -v — посмотреть, к какому репозиторию на GitHub подключён проект.

git remote add origin <ссылка> — подключить локальный проект к репозиторию на GitHub.

git push -u origin main — первый раз отправить ветку main на GitHub.

git push origin <ветка> — отправить определённую ветку на GitHub.

git fetch — проверить и скачать информацию о новых изменениях с GitHub.

Отмена изменений

git restore <файл> — отменить изменения в файле.

git restore --staged <файл> — отменить git add для файла.

git reset --soft HEAD~1 — отменить последний коммит, но оставить изменения в файлах.

git rm <файл> — удалить файл из проекта через Git.
